# AVAS Routing SW v1.7.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernize AVAS-BRV-wrapper-win to v1.7.0 by incorporating reverse-engineering (REA) findings into the RTP preview pipeline, fixing non-functional Factory Reset, MCU Reset, and Reboot operations, purging obsolete VEGA-1100 code, and revamping the UI/UX with PIN-locked (`00000000`) Advanced Settings and ultra-clean Single/Dual Link preview cards.

**Architecture:** 
- The video preview pipeline uses a unified port-5000 UDP multicast receiver with strict source-IP whitelist filtering (REA Report 06) and dual-path control (UART `set rtp igmp` vs BlueRiver thumbnail API).
- Hardware maintenance is bifurcated into MCU domain (`set system reboot\r\n`, `set factory default\r\n`) and BlueRiver AVP PHY domain (`reboot <MAC>`, `factory <MAC>`) with REST and Telnet dual fallbacks.
- The UI follows the `Operate` mode of Impeccable and UI-UX-Pro-Max: a high-contrast, uncluttered operator interface showing only `Previews` and `Multi-Link` tabs by default, stripping all maintenance buttons from preview cards, and securing Thermals & Diagnostics behind an 8-digit PIN (`00000000`) in `Settings`.

**Tech Stack:** C# .NET 8 (`net8.0-windows`), WPF, Microsoft.Web.WebView2, xUnit, System.Text.Json, VOIPS SDK.

**Spec:** REA Reports 00 through 07 (`REA_Reports/`), user request directives, and `PROJECT.md`.

## Global Constraints
- Target Framework: `net8.0-windows`
- Maintain 100% test pass rate across `AvasRoutingApp.Tests` and `E2ETests`.
- Zero tolerance for breaking changes in Multi-Link 10G/20G bonding or WebView2 embedding.
- No GDI or unmanaged memory leaks in video rasterization; write directly to `WriteableBitmap`.
- Advanced Settings PIN code is strictly `00000000` (8 zeros), session-persisted (relocks on restart).

## Review Focus
1. **MCU Line Terminators**: MCU UART commands (`set system reboot`, `set factory default`) must end with `\r\n` (ASCII 0x0D, 0x0A) or the hardware parser will ignore them.
2. **Telnet Disconnection Resilience**: All reset/reboot and preview start/stop commands must have REST fallback (`/api/device/{mac}`) if Telnet is unreachable.
3. **Source IP Demuxing Collisions**: Packets from non-target or unallocated IP addresses must be dropped at the socket layer before frame allocation.
4. **UI State Integrity on Lock/Unlock**: Unlocking Advanced Settings must dynamically reveal the tab without re-rendering or interrupting active preview streams.
5. **Zero VEGA Artifacts**: Complete removal of all VEGA constants, predicates, config toggles, and test suites without affecting AVAS-223 chip_0 discovery.
